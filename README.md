## 🚀 Selected Projects

### 🎧 Reliability-Aware Audio-Visual Speech Recognition
- Developed multimodal models using **AV-HuBERT, Whisper, and multimodal language models**
- Designed reliability-aware fusion and contrastive decoding methods
- Improved speech recognition robustness under noisy audio conditions

### 🧠 LLM-based Fraud Anomaly Detection
- Developed an explainable fraud detection pipeline using  
  **LLM Fine-tuning, LoRA, Retrieval, RAG, ReAct, and Reflexion**
- Combined a lightweight DNN classifier with an LLM through confidence-based routing
- Built a system that predicts fraud and generates natural-language explanations

### 👴 YOLOv8-based Elderly Care System
- Fine-tuned a **YOLOv8-based fall and abnormal behavior detection model**
- Achieved an mAP50–95 score of **0.674**
- Implemented a Flask-based web application for model inference and visualization

### 🎮 Startup & Product Development
- Co-founded a game startup and developed a story-driven game using **Unity**
- Experienced the full product lifecycle including development, testing, debugging, and release
- Deployed applications to the **App Store and Google Play Store**
