## 🔬 Research Highlights

### 🎤 Interspeech 2026 — Accepted · Oral · First Author

**Attention-Guided Reliability Scaling for Contrastive Decoding in Robust Audio-Visual Speech Recognition**

- Developed a training-free contrastive decoding method for robust Audio-Visual Speech Recognition
- Dynamically adjusted decoding strength using attention, energy, and entropy-based reliability signals
- Improved robustness while minimizing unnecessary intervention under clean conditions

### 🎧 IEEE ASRU 2025 — Accepted · Poster · Co-first Author

**Improving Noise Robust Audio-Visual Speech Recognition via Router-Gated Cross-Modal Feature Fusion**

- Designed a router-gated cross-modal fusion method for noisy Audio-Visual Speech Recognition
- Dynamically controlled audio and visual contributions according to modality reliability
- Evaluated the proposed method using AV-HuBERT and Whisper-based architectures

### 📄 IEEE TASLP — Major Revision · Co-author

**When to Intervene: Disagreement-Aware Contrastive Decoding for Robust Audio-Visual Speech Recognition**

- Studied when contrastive decoding should intervene during multimodal inference
- Used disagreement between model predictions to selectively control decoding
- Analyzed performance across clean and noisy speech conditions

## 🚀 Selected Projects

### 🎧 Reliability-Aware Audio-Visual Speech Recognition

- Developed multimodal speech recognition models using **AV-HuBERT, Whisper, and multimodal language models**
- Designed reliability-aware fusion, routing, and contrastive decoding methods
- Investigated how audio and visual modalities should be dynamically controlled under noisy conditions
- Conducted large-scale experiments using the **LRS3 audio-visual speech dataset**

### 🧠 LLM-based Fraud Anomaly Detection

- Participated in an industry research project for **Kim & Chang**
- Developed an explainable fraud detection pipeline using **LLM fine-tuning, LoRA, Retrieval, RAG, ReAct, and Reflexion**
- Converted tabular financial data into natural-language inputs for LLM inference
- Retrieved similar examples using vector representations and cosine similarity
- Combined a lightweight DNN classifier with an LLM through confidence-based routing
- Generated fraud predictions together with natural-language explanations and confidence scores

### 👴 YOLOv8-based Elderly Care System

- Fine-tuned a **YOLOv8-based fall and abnormal behavior detection model**
- Achieved an **mAP50–95 score of 0.674** for fall detection
- Implemented the full pipeline from model fine-tuning to a Flask-based web application
- Developed an AI monitoring system designed to support elderly safety and emergency response
